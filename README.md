# BaldQuant

Portfolio and price list for small Solana and Telegram bot jobs. Static HTML, CSS and
JavaScript, with a Three.js bonding-curve scene in the hero. No build step.

Live: https://balleing.github.io/baldquant/
Contact: [@BaldQuant on X](https://x.com/BaldQuant)

Run locally: `python3 -m http.server 8765`, then open http://127.0.0.1:8765.
